Installer l'application sur votre téléphone

Installation gratuite sur les téléphones Android et iPhone compatibles. Aucun passage par Play Store ou App Store n’est nécessaire.

Ouvrir la plateforme

Si le bouton « Installer l’application maintenant » apparaît, appuyez dessus. Sinon, suivez les étapes correspondant à votre téléphone.

Sur tous les téléphones Android

Cette application n’est pas réservée à Samsung. Elle est conçue pour les téléphones Android compatibles, notamment Samsung, Tecno, Infinix, Itel, Xiaomi, Redmi, Oppo, Realme, Vivo, Motorola et les autres marques Android.

  1. Ouvrez cette page dans le navigateur Google Chrome (méthode recommandée).
  2. Appuyez sur le menu ⋮ en haut à droite de Chrome.
  3. Choisissez Installer l'application ou Ajouter à l'écran d'accueil, selon l’option affichée.
  4. Appuyez sur Installer ou Ajouter pour confirmer.
  5. L’icône Daara Jazbul Quluub apparaîtra sur l’écran d’accueil.

Autres navigateurs Android : selon le navigateur et sa version, ouvrez son menu puis cherchez « Installer l’application » ou « Ajouter à l’écran d’accueil ». Si cette option n’apparaît pas, essayez avec Google Chrome à jour.

Vous avez ouvert le lien depuis Gmail, WhatsApp ou Facebook ? Ouvrez le menu de la page et choisissez « Ouvrir dans Chrome » avant de procéder à l’installation. Le bouton d’installation directe apparaît uniquement lorsque le navigateur prend en charge cette fonction.

Sur iPhone

  1. Ouvrez cette page dans le navigateur Safari.
  2. Appuyez sur le bouton Partager (carré avec une flèche vers le haut).
  3. Faites défiler puis choisissez Sur l'écran d'accueil ou Ajouter à l'écran d'accueil.
  4. Activez Ouvrir comme app web si cette option apparaît, puis appuyez sur Ajouter.
  5. L'icône apparaîtra sur l'écran d'accueil de votre iPhone.

Sur iPhone avec Google Chrome

  1. Ouvrez Google Chrome sur votre iPhone et accédez à cette page d'installation.
  2. Appuyez sur l'icône Partager à côté de la barre d'adresse.
  3. Dans le menu de partage, choisissez Ajouter à l'écran d'accueil. Faites défiler les actions si nécessaire.
  4. Vérifiez le nom Daara Jazbul Quluub, puis appuyez sur Ajouter.
  5. Revenez à l'écran d'accueil : l'icône de la plateforme doit y apparaître.

Avec Chrome sur iPhone, cette opération ajoute une icône de lancement. Selon iOS et le comportement du site, elle peut ouvrir la plateforme comme une app web ou comme un raccourci dans le navigateur. Pour l'affichage en mode application autonome, utilisez de préférence Safari et activez « Ouvrir comme app web » lorsque l'option est proposée.

À retenir

L'installation est gratuite et l'application se met à jour depuis la plateforme. Une connexion Internet reste nécessaire pour se connecter et consulter les informations, les cartes de membres, les commissions et les cotisations.

En cas de difficulté, ouvrez directement la plateforme avec le bouton ci-dessus et demandez de l'aide à l'administrateur.
